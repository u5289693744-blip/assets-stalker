# Folder: portfolio

Tutaj beda obliczenia portfela. Zgodnie z zasada projektu **wszystkie obliczenia
prowadzimy w dolarach (USD)**, a na PLN przeliczamy dopiero przy wyswietlaniu.

Planowane funkcje (kolejne kroki):
- laczenie transakcji w pozycje (np. wiele zakupow AAPL = jedna pozycja),
- sredni koszt zakupu (ile srednio zaplacono za jednostke),
- ilosc posiadana po uwzglednieniu sprzedazy,
- zysk/strata = aktualna wartosc minus koszt (znak dodatni = zysk, ujemny = strata).
