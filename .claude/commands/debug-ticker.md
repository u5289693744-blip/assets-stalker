Zbadaj, dlaczego symbol giełdowy "$ARGUMENTS" może się nie wczytywać lub nie pokazywać aktualnej ceny.

Wykonaj kolejno:

1. **Sprawdź format symbolu** — czy ticker jest zapisany poprawnie (wielkie litery, brak spacji, właściwa długość). Dla kryptowalut sprawdź, czy końcówka to `-USD` lub analogiczna para walutowa wymagana przez używane API.

2. **Przetestuj zapytanie do API** — wykonaj bezpośrednie zapytanie do API używanego w projekcie dla tego symbolu i pokaż odpowiedź. Wyjaśnij prostym językiem, co API zwróciło.

3. **Zidentyfikuj przyczynę** — na podstawie wyników powyższych kroków wyjaśnij, co jest przyczyną problemu. Może to być błędny ticker, nieobsługiwany rynek, limit zapytań do API lub inny powód.

4. **Zaproponuj rozwiązanie** — podaj konkretną propozycję naprawy i zapytaj o potwierdzenie przed wprowadzeniem jakichkolwiek zmian.

Opisuj wszystko prostym językiem. Nie pokazuj bloków kodu, chyba że użytkownik o to poprosi.
